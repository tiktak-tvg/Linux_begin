### Список команд для диагностики, мониторинга и аудита безопасности Linux
##### 🌐 Сетевой мониторинг и обнаружение уязвимостей
**nmap** — сканирование сети, обнаружение хостов, открытых портов и сервисов.

**nmap -sn <сеть>** — быстрое обнаружение активных хостов.

**nmap -sS -sV -O <цель>** — детальное сканирование портов, версий служб и ОС.

**nmap --script vuln <цель>** — проверка на известные уязвимости с помощью скриптов.

**netstat -tulnp / ss -tulnp** — просмотр открытых портов и прослушиваемых служб.

**tcpdump** — захват и анализ сетевого трафика в реальном времени.

**iftop** — мониторинг сетевой активности в реальном времени по соединениям.

**nethogs** — определение процессов, потребляющих трафик.

**arp-scan / netdiscover** — обнаружение устройств в локальной сети.

**dig / nslookup** — диагностика DNS, поиск misconfiguration и скрытых поддоменов.

**traceroute / mtr** — трассировка маршрута для диагностики сетевых проблем.

**unicornscan** — асинхронное сканирование TCP/UDP портов.

🔍 Аудит безопасности и поиск уязвимостей
**lynis audit system** — комплексный аудит безопасности системы (ядро, SSH, файлы, пользователи).

**chkrootkit / rkhunter** — поиск руткитов и вредоносного ПО.

**lsof -i -P -n** — список всех открытых сетевых соединений.

**find / -type f -perm -4000 2>/dev/null** — поиск файлов с SUID-битом (риск повышения привилегий).

**auditctl** — управление аудитом системы (из пакета auditd).

**pscap / capsh** — проверка Linux-способностей (capabilities) процессов и бинарных файлов.

**lscpu** — отображает уязвимости процессора (например, Spectre, Meltdown).

##### 🛡️ Мониторинг процессов и обнаружение вторжений
**ps aux** — список всех запущенных процессов.

**top / htop** — мониторинг процессов в реальном времени.

**ss -tulnp / netstat -tulnp** — выявление неавторизованных служб, слушающих порты.

**grep "Failed password" /var/log/auth.lo**g — поиск неудачных попыток входа (брутфорс).

**systemctl list-units --type=service** — список запущенных служб.

**lsof +L1** — поиск удалённых, но открытых файлов (может указывать на скрытую активность).

**find /proc/[0-9]*/fd -lname '*deleted*'** — альтернативный способ поиска скрытых файловых дескрипторов.

##### 📜 Анализ журналов и событий безопасности
**tail -f /var/log/syslog** — мониторинг системного журнала в реальном времени.

**grep "Failed password" /var/log/auth.log** — анализ неудачных попыток входа.

**last** — история успешных входов пользователей.

**who / w** — список текущих сессий пользователей.

**journalctl** — просмотр логов systemd с фильтрацией.

**dmesg** — сообщения ядра (ошибки оборудования, подозрительная активность).

##### ⚙️ Проверка конфигурации и усиление защиты
**cat /etc/passwd** — список всех пользователей (проверка на подозрительные учётки).

**cat /etc/shadow** — проверка теневых паролей (требует прав root).

**sudo cat /etc/sudoers / sudoers** — проверка прав sudo (наличие избыточных привилегий).

**iptables -L / nft list ruleset** — просмотр правил файрвола.

**systemctl status <служба>** — проверка состояния критичных служб.

**grep "PermitRootLogin" /etc/ssh/sshd_config** — проверка, разрешён ли вход root по SSH.

**grep "PasswordAuthentication" /etc/ssh/sshd_config** — проверка, разрешена ли аутентификация по паролю.

**chattr +i <файл>** — установка неизменяемого бита для защиты файлов от изменений.

##### 🧰 Специализированные инструменты
**Snort / Suricata** — системы обнаружения вторжений (IDS/IPS) на основе правил.

**Wireshark / tshark** — глубокий анализ сетевых пакетов.

**eBPF / bpftrace** — продвинутый мониторинг системных вызовов и сетевых событий.

**Fail2ban** — автоматическая блокировка IP после повторных неудачных попыток входа.

**AIDE / Tripwire** — контроль целостности файлов (IDS для файловой системы).

**ClamAV** — антивирусное сканирование.

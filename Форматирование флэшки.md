Для форматирования флешки в Linux, выполните следующие шаги:<br>
1. Воткните флешку в вход USB вашего компьютера.<br>
2. Отыщите имя устройства, которое было присвоено системой вашей флешке.<br>
Выполните в командной строке команду:
```bash
dmesg | tail
```
Результатом будет вид типа:<br>
sdb в квадратных скобках и есть имя устройства, которое было присвоено
системой вашей флешке.<br>
3. " Отмонтируем" нашу флешку, выполнив команду:
```bash
# umount /dev/sdb
```
4. К примеру, нам необходимо, чтобы флешка была отформатирована в формате
``fat32 (в Linux это - vfat)``. <br>выполните команду:
```
$ sudo mkfs.vfat /dev/sdb
```
После успешного выполнения этой команды флешка будет отформатирована.<br>
Если вам необходимо отформатировать флешку в другом формате, вам доступна
возможность форматирования в других форматах. <br>Вот список возможных
форматов и соответствующих команд:
```
mkfs.ext2 - EXT2
mkfs.ext3 - EXT3
mkfs.ext4 - EXT4
mkfs.bfs - BFS
mkfs.msdos - MSDOS
mkfs.reiserfs - ReiserFS
mkfs.minix - Minix
mkfs.ntfs - NTFS
mkfs.vfat - VFAT (Fat32)
```
Какой тип файловой системы выбрать вам, решайте сами. Все зависит от ваших
нужд.<br>
Для тех, кто любит давать устройствам "имена" в виде "лейблов", при
форматировании доступен ключ -I.<br>
Команда:
```
sudo mkfs.ext3 -I -n 'Work' /dev/sdb
```
позволит выполнить форматирование флешки опознанной системой как
устройство sdb. <br>Флешка будет отформатирована в файловой системе ext3.

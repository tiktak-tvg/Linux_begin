# Шпаргалка по командам редактора Vim

Практический справочник основных режимов, горячих клавиш и команд текстового редактора **Vim** для системного администрирования и разработки.

---

## 1. Режимы работы Vim

Vim работает в нескольких режимах. По умолчанию редактор открывается в **обычном режиме (Normal mode)**.

| Клавиша | Переход в режим | Описание |
| :--- | :--- | :--- |
| **`Esc`** или **`Ctrl + [`** | **Обычный (Normal)** | Режим навигации и выполнения команд (исходный режим). |
| **`i`** | **Вставки (Insert)** | Ввод текста **перед** курсором. |
| **`I`** | **Вставки (Insert)** | Ввод текста в **начале** текущей строки. |
| **`a`** | **Вставки (Insert)** | Ввод текста **после** курсора. |
| **`A`** | **Вставки (Insert)** | Ввод текста в **конце** текущей строки. |
| **`o`** | **Вставки (Insert)** | Создание новой строки **ниже** текущей и переход в режим ввода. |
| **`O`** | **Вставки (Insert)** | Создание новой строки **выше** текущей и переход в режим ввода. |
| **`v`** | **Визуальный (Visual)** | Посимвольное выделение текста. |
| **`V`** | **Визуальный построчный** | Выделение целых строк. |
| **`Ctrl + v`** | **Визуальный блочный** | Прямоугольное (блочное) выделение столбцов текста. |
| **`:`** | **Командный (Command-line)** | Ввод команд в нижней строке (сохранение, выход, поиск и замена). |

## 2. Сохранение и выход (в командном режиме `:`)

| Команда | Действие |
| :--- | :--- |
| **`:w`** | Сохранить файл (записать изменения на диск). |
| **`:w имя_файла`** | Сохранить файл под новым именем («Сохранить как»). |
| **`:w !sudo tee %`** | Сохранить файл от имени `root`, если забыли запустить Vim через `sudo`. |
| **`:q`** | Выйти из редактора (если нет несохранённых изменений). |
| **`:q!`** | Принудительно выйти **без сохранения** изменений. |
| **`:wq`** или **`:x`** или **`ZZ`** | Сохранить изменения и выйти из редактора. |
| **`ZQ`** | Выйти без сохранения (аналог `:q!`). |
| **`:e!`** | Отменить все несохранённые изменения и перезагрузить файл с диска. |

## 3. Навигация по файлу (в обычном режиме)

### Базовое перемещение
| Клавиша | Действие |
| :--- | :--- |
| **`h` / `j` / `k` / `l`** | Влево / Вниз / Вверх / Вправо (аналог стрелок). |
| **`w`** | Перейти в начало **следующего** слова. |
| **`b`** | Перейти в начало **предыдущего** слова. |
| **`e`** | Перейти в **конец** текущего или следующего слова. |
| **`0`** (ноль) | Перейти в самое начало текущей строки. |
| **`^`** | Перейти к первому непробельному символу строки. |
| **`$`** | Перейти в конец текущей строки. |

### Быстрый переход по документу
| Клавиша | Действие |
| :--- | :--- |
| **`gg`** | Перейти в самое **начало файла** (1-я строка). |
| **`G`** | Перейти в самый **конец файла** (последняя строка). |
| **`15G`** или **`:15`** | Перейти на **15-ю строку** файла. |
| **`Ctrl + f`** | Прокрутить экран на одну страницу **вниз** (Page Down). |
| **`Ctrl + b`** | Прокрутить экран на одну страницу **вверх** (Page Up). |
| **`Ctrl + d`** | Прокрутить на **пол-экрана вниз**. |
| **`Ctrl + u`** | Прокрутить на **пол-экрана вверх**. |
| **`%`** | Перейти к парной скобке (`()`, `[]`, `{}`). |

## 4. Редактирование, копирование и удаление

> **Совет:** Перед большинством команд можно поставить число (множитель). Например, `3dd` удалит 3 строки, а `5yy` скопирует 5 строк.

### Удаление и вырезание (помещается в буфер обмена Vim)
| Команда | Действие |
| :--- | :--- |
| **`x`** | Удалить символ под курсором (аналог `Delete`). |
| **`X`** | Удалить символ перед курсором (аналог `Backspace`). |
| **`dd`** | Вырезать (удалить) всю текущую строку. |
| **`dw`** | Удалить слово от курсора до начала следующего слова. |
| **`d$`** или **`D`** | Удалить текст от курсора до конца строки. |
| **`d0`** | Удалить текст от курсора до начала строки. |
| **`dG`** | Удалить всё от текущей строки до конца файла. |

### Копирование и вставка
| Команда | Действие |
| :--- | :--- |
| **`yy`** | Скопировать (yank) всю текущую строку. |
| **`yw`** | Скопировать слово. |
| **`y$`** | Скопировать текст от курсора до конца строки. |
| **`p`** | Вставить из буфера **после** курсора (или строкой ниже). |
| **`P`** | Вставить из буфера **перед** курсором (или строкой выше). |

### Изменение текста и отмена действий
| Команда | Действие |
| :--- | :--- |
| **`u`** | **Отменить** последнее действие (Undo). |
| **`Ctrl + r`** | **Вернуть** отменённое действие (Redo). |
| **`.`** (точка) | Повторить последнюю выполненную команду редактирования. |
| **`r<символ>`** | Заменить один символ под курсором на указанный (без перехода в режим вставки). |
| **`cc`** | Удалить содержимое текущей строки и перейти в режим вставки. |
| **`cw`** | Удалить слово и перейти в режим вставки. |
| **`J`** | Объединить текущую строку со следующей. |
| **`>>`** / **`<<`** | Сдвинуть строку вправо / влево на один отступ (`shiftwidth`). |

## 5. Поиск и замена

### Поиск по тексту
| Команда | Действие |
| :--- | :--- |
| **`/текст`** | Поиск `текст` **вперёд** по файлу (нажать `Enter` для запуска). |
| **`?текст`** | Поиск `текст` **назад** по файлу. |
| **`n`** | Перейти к **следующему** совпадению. |
| **`N`** | Перейти к **предыдущему** совпадению. |
| **`*`** | Найти следующее вхождение слова, на котором сейчас стоит курсор. |
| **`:noh`** | Снять жёлтую подсветку результатов поиска. |

### Поиск и замена (`:s`)
| Команда | Действие |
| :--- | :--- |
| **`:s/старое/новое/`** | Заменить **первое** совпадение в текущей строке. |
| **`:s/старое/новое/g`** | Заменить **все** совпадения в текущей строке. |
| **`:%s/старое/новое/g`** | Заменить **все** совпадения во всём файле. |
| **`:%s/старое/новое/gc`** | Заменить во всём файле с **подтверждением** каждой замены (`y`/`n`/`a`/`q`). |
| **`:10,20s/старое/новое/g`** | Заменить все совпадения только в диапазоне строк с 10 по 20. |

## 6. Работа с окнами и вкладками

| Команда | Действие |
| :--- | :--- |
| **`:sp файл`** | Открыть файл в **горизонтальном** разделении окна (Split). |
| **`:vsp файл`** | Открыть файл в **вертикальном** разделении окна (Vertical Split). |
| **`Ctrl + w` затем `w`** | Переключиться между открытыми окнами. |
| **`Ctrl + w` затем `h/j/k/l`** | Перейти в окно слева / снизу / сверху / справа. |
| **`Ctrl + w` затем `q`** | Закрыть текущее окно. |
| **`:tabe файл`** | Открыть файл в новой **вкладке**. |
| **`gt`** / **`gT`** | Переключиться на следующую / предыдущую вкладку. |

## 7. Полезные настройки (вводятся через `:` или в `~/.vimrc`)

| Команда | Действие |
| :--- | :--- |
| **`:set number`** (или `:set nu`) | Включить нумерацию строк. |
| **`:set nonumber`** (или `:set nonu`) | Выключить нумерацию строк. |
| **`:set relativenumber`** | Включить относительную нумерацию строк (удобно для команд вида `5j`, `10dd`). |
| **`:set paste`** | Включить режим вставки из внешнего буфера (отключает автоотступы при вставке мышью). |
| **`:set nopaste`** | Выключить режим вставки. |
| **`:set ignorecase`** (или `:set ic`) | Игнорировать регистр при поиске. |
| **`:syntax on`** | Включить подсветку синтаксиса. |
| **`:set expandtab`** | Заменять символы табуляции пробелами. |
| **`:set tabstop=4 shiftwidth=4`** | Установить ширину табуляции и отступа в 4 пробела. |

## Справочник утилит Linux

В документе собрано описание 163 утилит Linux, сгруппированных по функциональным категориям: назначение, поддерживаемые дистрибутивы и пакеты для установки.

> **Примечание:** Под **RHEL-подобными** подразумеваются RHEL, CentOS, AlmaLinux, Rocky Linux, РЕД ОС, Альт (частично). Под **Debian-подобными** — Debian, Ubuntu, Astra Linux.

---

## 1. Базовые команды работы с файлами, текстом и оболочкой

Большинство этих утилит входят в состав базового набора GNU (`coreutils`) или самой оболочки (`bash`) и **предустановлены во всех дистрибутивах Linux** по умолчанию.

| Утилита | Назначение | ОС и пакет установки |
| :--- | :--- | :--- |
| **`cat`** | Вывод содержимого файлов в терминал, их объединение. | Все Linux (`coreutils`, предустановлена). |
| **`cd`** | Смена текущего рабочего каталога. | Все Linux (встроена в оболочку `bash`/`sh`). |
| **`cp`** | Копирование файлов и директорий. | Все Linux (`coreutils`, предустановлена). |
| **`cut`** | Вырезание колонок или символов из строк текста. | Все Linux (`coreutils`, предустановлена). |
| **`echo`** | Вывод текста или значений переменных на экран. | Все Linux (`coreutils` / встроена в `bash`). |
| **`find`** | Поиск файлов и каталогов по имени, размеру, дате, правам. | Все Linux (`findutils`, предустановлена). |
| **`grep`** | Поиск текста по шаблонам (регулярным выражениям). | Все Linux (`grep`, предустановлена). |
| **`gzip`** | Сжатие и распаковка файлов в формате `.gz`. | Все Linux (`gzip`, предустановлена). |
| **`head`** | Вывод первых строк файла (по умолчанию 10). | Все Linux (`coreutils`, предустановлена). |
| **`hexdump`** | Просмотр содержимого файлов в шестнадцатеричном (hex) виде. | Все Linux (`util-linux`, обычно предустановлена). |
| **`less`** | Постраничный просмотр больших текстовых файлов и логов. | Все Linux (`less`, предустановлена). |
| **`ls`** | Просмотр списка файлов и каталогов с их атрибутами. | Все Linux (`coreutils`, предустановлена). |
| **`mkdir`** | Создание новых директорий. | Все Linux (`coreutils`, предустановлена). |
| **`mv`** | Перемещение и переименование файлов/директорий. | Все Linux (`coreutils`, предустановлена). |
| **`nano`** | Простой консольный текстовый редактор. | Все Linux. Пакет `nano` (`dnf/yum/apt install nano`). |
| **`printf`** | Форматированный вывод текста (аналог `echo` с шаблонами). | Все Linux (`coreutils` / встроена в `bash`). |
| **`rm`** | Удаление файлов и директорий. | Все Linux (`coreutils`, предустановлена). |
| **`rsync`** | Быстрое копирование и синхронизация файлов (локально и по сети). | Все Linux. Пакет `rsync` (`dnf/apt install rsync`). |
| **`sed`** | Потоковый текстовый редактор (поиск и замена текста без открытия файла). | Все Linux (`sed`, предустановлена). |
| **`sha256sum`** | Вычисление и проверка контрольных сумм SHA-256. | Все Linux (`coreutils`, предустановлена). |
| **`shred`** | Безвозвратное удаление файлов путём многократной перезаписи. | Все Linux (`coreutils`, предустановлена). |
| **`sleep`** | Приостановка выполнения скрипта или команды на заданное время. | Все Linux (`coreutils`, предустановлена). |
| **`sort`** | Сортировка строк в текстовых файлах. | Все Linux (`coreutils`, предустановлена). |
| **`tail`** | Вывод последних строк файла (с ключом `-f` — чтение логов в реальном времени). | Все Linux (`coreutils`, предустановлена). |
| **`tar`** | Создание и распаковка архивов (`.tar`, `.tar.gz`, `.tar.xz`). | Все Linux (`tar`, предустановлена). |
| **`tee`** | Вывод данных одновременно на экран и запись в файл. | Все Linux (`coreutils`, предустановлена). |
| **`touch`** | Создание пустого файла или обновление времени его изменения. | Все Linux (`coreutils`, предустановлена). |
| **`truncate`** | Уменьшение или увеличение размера файла до заданного значения. | Все Linux (`coreutils`, предустановлена). |
| **`uniq`** | Удаление или подсчёт повторяющихся соседних строк. | Все Linux (`coreutils`, предустановлена). |
| **`unzip`** | Распаковка `.zip` архивов. | Все Linux. Пакет `unzip` (`dnf/apt install unzip`). |
| **`watch`** | Периодический запуск указанной команды с выводом результата на экран. | Все Linux (`procps-ng` в RHEL / `procps` в Debian). |
| **`zip`** | Создание `.zip` архивов. | Все Linux. Пакет `zip` (`dnf/apt install zip`). |

## 3. Безопасность, аудит (Auditd) и SELinux

Большая часть утилит SELinux и `authselect` характерна для **RHEL-подобных систем** (RHEL, CentOS, РЕД ОС, AlmaLinux, Rocky Linux). В Debian/Ubuntu по умолчанию используется AppArmor, но пакеты SELinux там тоже можно установить.

| Утилита | Назначение | ОС и пакет установки |
| :--- | :--- | :--- |
| **`aide`** | Контроль целостности файлов и каталогов (обнаружение несанкционированных изменений). | Все Linux. Пакет `aide` (`dnf/apt install aide`). |
| **`auditctl`** | Управление подсистемой аудита ядра Linux в реальном времени (правила, статус). | Все Linux. Пакет `audit` (RHEL) / `auditd` (Debian). |
| **`auditd`** | Демон (служба) аудита, записывающий события безопасности на диск. | Все Linux. Пакет `audit` (RHEL) / `auditd` (Debian). |
| **`aureport`** | Генерация сводных отчётов на основе логов аудита (`auditd`). | Все Linux. Пакет `audit` (RHEL) / `auditd` (Debian). |
| **`ausearch`** | Поиск конкретных событий в журналах аудита (`auditd`). | Все Linux. Пакет `audit` (RHEL) / `auditd` (Debian). |
| **`authselect`** | Настройка профилей аутентификации (SSSD, Winbind, локальные файлы) и PAM. | RHEL 8/9+, Fedora, РЕД ОС. Пакет `authselect`. |
| **`autrace`** | Трассировка системных вызовов конкретного процесса для аудита (аналог `strace`). | Все Linux. Пакет `audit` (RHEL) / `auditd` (Debian). |
| **`chcon`** | Временное изменение контекста безопасности SELinux для файла или каталога. | RHEL-подобные (в Debian — пакет `selinux-utils`). Входит в `coreutils`. |
| **`evmctl`** | Управление цифровыми подписями и хешами IMA/EVM для проверки целостности файлов на уровне ядра. | Все Linux (актуально для сертифицированных ОС, РЕД ОС, Astra). Пакет `ima-evm-utils`. |
| **`fapolicyd-cli`** | Управление фреймворком `fapolicyd` (белые списки запускаемых приложений). | RHEL 8/9+, Fedora, РЕД ОС. Пакет `fapolicyd`. |
| **`getenforce`** | Проверка текущего режима работы SELinux (`Enforcing`, `Permissive`, `Disabled`). | RHEL-подобные (`libselinux-utils`). В Debian — `selinux-utils`. |
| **`getsebool`** | Просмотр значений логических переключателей (booleans) политик SELinux. | RHEL-подобные (`libselinux-utils`). В Debian — `selinux-utils`. |
| **`ipa`** | Консольный клиент управления доменом FreeIPA (пользователи, хосты, политики). | RHEL-подобные, РЕД ОС, Astra, Debian. Пакет `ipa-client` / `freeipa-client`. |
| **`openssl`** | Универсальный криптографический инструмент (создание ключей, сертификатов TLS, шифрование). | Все Linux. Пакет `openssl` (`dnf/apt install openssl`). |
| **`restorecon`** | Восстановление контекста SELinux по умолчанию для файлов согласно политике. | RHEL-подобные (`policycoreutils`). В Debian — `policycoreutils`. |
| **`selftest`** | Утилита самотестирования криптографических модулей или аппаратных компонентов (зависит от реализации). | Зависит от СЗИ/ОС (например, КриптоПро, либо встроенные тесты модулей ядра/OpenSSL). |
| **`semanage`** | Постоянная настройка политик SELinux (порты, контексты файлов, пользователи). | RHEL-подобные. Пакет `policycoreutils-python-utils` (в старых — `policycoreutils-python`). |
| **`semodule`** | Управление загруженными модулями политик SELinux (установка, удаление, список). | RHEL-подобные (`policycoreutils`). |
| **`semodule_package`** | Сборка скомпилированного модуля политики SELinux в пакет `.pp`. | RHEL-подобные (`policycoreutils-devel`). |
| **`sestatus`** | Вывод подробного статуса SELinux (режим, активная политика, версии). | RHEL-подобные (`policycoreutils`). |
| **`setenforce`** | Переключение режима SELinux на лету между `Enforcing` (1) и `Permissive` (0). | RHEL-подобные (`libselinux-utils`). |
| **`setfiles`** | Массовая инициализация/восстановление контекстов безопасности SELinux для файловой системы. | RHEL-подобные (`policycoreutils`). |
| **`setsebool`** | Включение или отключение логических переключателей (booleans) SELinux. | RHEL-подобные (`policycoreutils`). |

| **`timedatectl`** | Управление системным временем, часовым поясом и синхронизацией NTP. | Все современные Linux с `systemd` (пакет `systemd`). |
